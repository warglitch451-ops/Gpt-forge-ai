Help & documentation

A practical guide to this prototype.

Creating a website

Describe the site, choose settings, then generate a local starter or select a template. Open Code Studio to inspect the source.

Editing

Select HTML, CSS or JavaScript, edit the code, and click Apply & preview. Undo returns to the last applied editor snapshot.

Saving

Projects are saved in this browser using localStorage. They do not sync across devices. Clearing browser data can remove them, so export backups regularly.

AI generation

The built-in starter generator and quick edits are local rules, not generative AI. Genuine AI needs a backend endpoint implementing your generation contract. This app does not invent a working connection.

Security

The preview uses a sandboxed iframe. Do not paste untrusted code into a production system. This prototype is not a replacement for a hardened multi-user SaaS backend.
