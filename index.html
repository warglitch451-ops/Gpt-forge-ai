GET STARTED

From idea to launch.

Everything you need to try this single-file prototype.

01 — Run it

Save this complete file as index.html. Open it in a modern browser or publish it using GitHub Pages. Sample website mode works without an API key.

02 — Configure Gemini

Open Google AI Studio, create a Gemini API key, then open AI Settings in ForgeAI Studio. Enter your key and a currently supported model ID, save settings, and test the connection.

Official links: Get an API key · Model documentation

03 — Generate and edit

Write a detailed prompt, choose a style, and generate. Use AI design assistant for bigger changes, manual controls for simple changes, and Code Studio for direct HTML edits.

04 — Save and export

Save a draft to store it in this browser, then download the current website using Export HTML. Keep backups of your code before making major edits.

For production: move Gemini calls to a backend you control. Store the API key as a server-side secret, add authentication and rate limits, validate output, and never put a private API key in a public HTML file.
