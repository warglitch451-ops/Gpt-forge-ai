Generation mode

Gemini API key

For private testing only. A key entered here is visible to the browser and can be extracted from a public website. Do not use a production or billing-enabled secret key here.

Production security: keep secret API keys on a server, not in public JavaScript. GitHub Pages can host this frontend but cannot run a private backend itself.
GET STARTED

Build smarter with ForgeAI.

Everything you need to start creating.

1. Describe your idea

Explain your business, audience, desired sections and design style. Specific prompts generally create more relevant websites.

2. Generate and customize

Use local generation for a no-key prototype, or Gemini mode for AI-assisted HTML generation. Review the output before publishing.

3. Preview and edit

Check desktop and mobile layouts. Apply code edits or use the design assistant to make supported changes.

4. Export and publish

Export a standalone HTML file. For multi-page sites, server functionality, private API keys, databases and authentication, you'll need additional files or backend services.

This is a frontend application. User accounts, cloud project syncing, real subscriptions and secure production AI requests are not implemented in this single file.
